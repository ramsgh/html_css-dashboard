# DevMetrics - Full Stack & AI Syllabus (Day 4 - Day 8) CSS Master Project

This project covers 100% of the topics from Day 4 through Day 8 in the Full Stack & AI Developer curriculum:

- **Day 4**: Selectors (element, class, ID, attribute, pseudo-classes, pseudo-elements), CSS specificity, cascade, HSL/RGB colors, rem/em/vw/vh units.
- **Day 5**: Box model, border-box, display types, position types (static, relative, absolute, fixed, sticky), z-index, overflow, float & clearfix.
- **Day 6**: Flexbox layouts (direction, justify, align, gap, wrap, flex-grow), Holy Grail layout components (Header, Sidebar, Main, Footer).
- **Day 7**: CSS Grid layouts, repeat(), minmax(), fr unit, auto-fit responsive grid matrix.
- **Day 8**: Responsive web design, mobile-first breakpoints (480px, 768px, 1024px), clamp typography, picture element responsive images.
